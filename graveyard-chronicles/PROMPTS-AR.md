# Graveyard Chronicles -- Gemini Image Generation Prompts (Arabic / العربية)

> **RTL Notice:** Arabic is a right-to-left (RTL) language. Gemini may struggle with Arabic script rendering in generated images. When adding narration box text overlays, specify right-to-left text direction. You may need to add Arabic text as post-production overlays rather than relying on Gemini to render Arabic script correctly. The visual/image prompts remain in English since Gemini needs English prompts for image generation.

## Global Style Guide

**Use this prefix for EVERY prompt to maintain consistency:**

> Pixel art comic book panel, dark gothic graveyard aesthetic, 16-bit retro style, color palette: deep purples, blacks, dark teals, muted greens, occasional neon purple/violet glow. Tombstones, crypts, fog, dead trees. Style reference: Solana Graveyard Hackathon pixel art — dark, atmospheric, cinematic. No cute or cartoonish elements. Gritty, moody, graphic novel energy. High detail pixel art.

## Production Notes (Arabic Version)

1. **RTL Text Direction:** All Arabic narration boxes must use right-to-left text direction. Set `dir="rtl"` if rendering in HTML/CSS overlays.
2. **Font Selection:** Use an Arabic-compatible gothic or decorative font. Recommended: Amiri, Scheherazade New, or Noto Naskh Arabic for readability in pixel art overlays.
3. **Gemini Limitations:** Gemini may not render Arabic script accurately in generated images. Plan to add Arabic text as post-production overlays using image editing software (Photoshop, GIMP, Figma).
4. **Mixed Direction Text:** Some narration boxes contain both English names (protocol names like "Exchange Art", "DRiP") and Arabic text. Ensure proper bidirectional (bidi) text rendering so English terms flow left-to-right within the right-to-left Arabic context.
5. **Same Images:** Use the exact same generated pixel art images as the English version. Only the narration box text overlays change.
