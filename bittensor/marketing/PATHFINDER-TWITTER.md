## Thread

### 1/6 - The Problem
```
You want to move $50K from ETH to USDC on Arbitrum.

You get quoted 0.3% slippage.
You receive $49,100.

Where did $400 go?

• Low-liquidity detours
• MEV sandwiches
• Hidden spreads

Nobody is incentivized to find you the best route.
```

### 2/6 - The Solution
```
PathFinder changes the game:

Miners compete to produce the most accurate cross-chain routes.

Validators verify predictions against actual on-chain execution.

Miners who find better routes earn more TAO.
Miners who lie get slashed.

Simple, brutal, effective.
```

### 3/6 - How It Works
```
Every 30 minutes:

1. Validators broadcast intent batch
2. Miners compute optimal routes
3. Commit-reveal prevents copying
4. 5% of routes executed for ground truth
5. Scores = TAO distribution

No order flow games.
No kickbacks.
Just accuracy.
```

### 4/6 - Why Bittensor
```
Why build this on @opentensor?

• Emissions align miners to accuracy, not volume
• Yuma Consensus provides trustless verification
• dTAO lets new subnets compete on merit
• SN10 proved DeFi optimization works here

Same model as Sturdy. Different application.
```

### 5/6 - Why Now
```
Cross-chain volume is exploding:
• 10x growth in 2 years
• MEV problem getting worse
• No decentralized alternative

PathFinder fills the gap:

Decentralized + Broad coverage = unoccupied territory.
```
