Miner Guide

Tasks, inputs, outputs, and how to build edge

The Task

Miners monitor DeFi lending positions and predict liquidations.

  1. Index positions from supported protocols (Aave V3, Compound V3, Morpho)
  2. Track health factors, collateral values, debt amounts
  3. Analyze market conditions and price trends
  4. Predict which positions will liquidate within 6 hours

What Makes Liquidation Prediction Hard

This isn't just price prediction. Miners must understand:

Factor Why It Matters
Protocol mechanics Liquidation thresholds vary by asset and protocol
Oracle delays Chainlink heartbeat means price updates aren't instant
Borrower behavior Will they add collateral? Repay debt?
Liquidator dynamics When gas is high, liquidators wait
Cascading effects One liquidation can trigger others

A miner who only predicts price will underperform one who understands these factors.

Input Format

Validators provide position snapshots at the start of each epoch:

{
  "epoch": "2026-02-05T14:00:00Z",
  "positions": [
    {
      "id": "aave_v3_eth_0x1234",
      "protocol": "aave_v3",
      "chain": "ethereum",
      "user": "0x1234...abcd",
      "health_factor": "1.15",
      "collateral_usd": "100000",
      "debt_usd": "75000",
      "collateral_assets": ["WETH"],
      "debt_assets": ["USDC"]
    }
  ],
  "market_data": {
    "eth_price_usd": 2500,
    "eth_24h_change": -0.05,
    "gas_price_gwei": 30
  }
}

Only at-risk positions are included. Validators filter to positions with Health Factor between 1.0 and 1.5.

Output Format

Miners submit predictions within the 10-minute prediction window:

{
  "miner_id": "5F3sa...",
  "epoch": "2026-02-05T14:00:00Z",
  "predictions": [
    {
      "position_id": "aave_v3_eth_0x1234",
      "will_liquidate": true,
      "time_window_hours": [2, 6],
      "confidence": 0.75
    },
    {
      "position_id": "aave_v3_eth_0x5678",
      "will_liquidate": false,
      "confidence": 0.90
    }
  ],
  "commitment_hash": "0xabc..."
}

Field Descriptions

Field Description
will_liquidate Binary prediction: will this position be liquidated?
time_window_hours Predicted time range for liquidation (for lead time scoring)
confidence 0.0-1.0 confidence level (used for calibration scoring)
commitment_hash Hash of predictions for commit-reveal mechanism

Commit-Reveal Mechanism

To prevent miners from copying each other:

  1. Commit phase (0-5 min): Miners submit hash of their predictions
  2. Reveal phase (5-10 min): Miners reveal actual predictions
  3. Predictions must match the committed hash

This ensures all predictions are made independently.

What Separates Good Miners from Bad

Edge Description
Better price models More accurate volatility forecasting
Whale tracking Monitoring large wallet movements
Protocol expertise Understanding Aave-specific mechanics
Historical analysis Learning from past liquidation patterns
Real-time data Faster position monitoring

Scoring Summary

Your predictions are scored on:

  • Precision (40%): Of your "will liquidate" predictions, how many were correct?
  • Recall (30%): Of all liquidations that happened, how many did you predict?
  • Lead Time (20%): How early were your correct predictions? (requires 50%+ precision)
  • Calibration (10%): Does your confidence match your actual accuracy?

Don't spam predictions. Predicting everything gives high recall but tanks your precision. The 40% precision weight is designed to prevent this.

Tips for New Miners

  1. Start conservative. Better to have high precision on fewer predictions than low precision on many.
  2. Understand the protocols. Aave, Compound, and Morpho have different liquidation mechanics.
  3. Watch for oracle updates. Chainlink price updates often trigger liquidations.
  4. Track gas prices. High gas can delay liquidations as liquidators wait.
  5. Learn from history. Use historical replay mode to test your model on past data.
