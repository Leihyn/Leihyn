# DeFi Comic Series — Style Guide & Character Bible

## How to Use These Scripts

Each issue has panel-by-panel **Gemini prompts** you can copy-paste directly. Add dialogue as text overlays after generating images.

---

## Visual Style (paste this prefix before every panel prompt)

```
Digital comic book art style, clean linework, vibrant flat colors, cel-shaded,
inspired by Invincible and Spider-Verse aesthetics. Bold outlines, expressive
characters, modern and diverse cast. Speech bubble space preserved in
composition. 16:9 aspect ratio.
```

## Recurring Characters

### Kael (The Guide)
```
Young Black male, early 20s, short locs, confident relaxed expression,
wears a dark hoodie with a glowing blockchain-node pattern on the chest,
fingerless gloves, futuristic sneakers. Carries a transparent holographic
tablet. He is the narrator/teacher figure.
```

### Nia (The Newcomer)
```
Young Black female, early 20s, natural TWA hairstyle, curious wide eyes,
wears a yellow jacket over a white tee, jeans, and boots. She is the
audience stand-in — asks the questions readers are thinking.
```

### The Vault (Recurring Location)
```
A massive glowing digital vault interior, like a futuristic bank crossed
with a server room. Floating holographic screens, streams of light
representing token flows, glass floors showing code running beneath.
This is the "DeFi world" the characters enter to visualize concepts.
```

## Color Coding (for concept consistency)

- **Blue/Cyan** = Stablecoins, safety, lending (Aave)
- **Pink/Magenta** = Trading, swaps, DEX (Uniswap)
- **Orange/Gold** = Rewards, yield, fees
- **Green** = Profit, growth, bullish
- **Red** = Risk, loss, danger
- **Purple** = Governance, voting, power

## Panel Layout Convention

- **Full-page splash**: Opening and closing panels of each issue
- **3-4 panels per page**: Standard explanation sequences
- **Wide cinematic panel**: Analogy reveals and "aha moment" scenes
- Dialogue goes in white speech bubbles with black text
- Narrator boxes are dark purple with white text (Kael's voiceover)
